# PCB / Electronics Portfolio — GitHub Pages

Готовый статический сайт-портфолио. Никакой сборки и зависимостей не требуется.

## Что заменить перед публикацией

1. `index.html`
   - имя / должность;
   - контакты в блоке `#contact`;
   - описания проектов;
   - названия и теги проектов.
2. Заменить изображения в папке `assets/` своими JPG/PNG/WebP.
3. Если нужен PDF резюме — положить файл как `assets/resume.pdf`. Если нет — удалить соответствующую кнопку.

### Рекомендуемые изображения на один проект

- 1 главное фото или 3D-рендер;
- 1 фото собранной платы;
- 1 скрин PCB layout;
- 1 фрагмент схемы;
- при необходимости 1 фото процесса отладки.

Оптимально использовать изображения шириной 1400–2000 px и сжимать их перед загрузкой.

## Публикация через GitHub Pages

1. Создать репозиторий. Для личного сайта удобно назвать его `USERNAME.github.io`.
2. Загрузить содержимое этой папки в корень репозитория.
3. Открыть `Settings` → `Pages`.
4. В `Build and deployment` выбрать `Deploy from a branch`.
5. Выбрать ветку `main` и папку `/(root)`, затем `Save`.
6. После публикации сайт будет доступен по адресу `https://USERNAME.github.io/` (для репозитория с таким названием).

Файл `.nojekyll` оставлен специально, чтобы GitHub Pages отдавал сайт как обычные статические файлы без обработки Jekyll.

## Быстрый локальный просмотр

Можно просто открыть `index.html` двойным кликом. Для более корректной проверки из папки проекта:

```bash
python -m http.server 8000
```

Затем открыть `http://localhost:8000`.
