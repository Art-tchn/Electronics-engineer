# Сайт-портфолио инженера

Готовый статический сайт для GitHub Pages. Сборка и дополнительные библиотеки не нужны: достаточно загрузить файлы в репозиторий и включить публикацию.

## Файлы

- `index.html` — текст и структура сайта.
- `styles.css` — оформление, цвета и адаптивная версия.
- `script.js` — мобильное меню, анимация и обработка фотографий.
- `.nojekyll` — отключает обработку сайта через Jekyll.
- `README.md` — эта инструкция.

## 1. Укажите свои данные

Откройте `index.html` и замените:

- `Артём [Фамилия]` — на имя и фамилию;
- `your.email@example.com` — на e-mail;
- `USERNAME` — на имя пользователя GitHub и Telegram;
- при необходимости тексты разделов «Обо мне», «Навыки» и «Проекты».

Также замените имя внутри тега `<title>` в верхней части `index.html`.

## 2. Добавьте фотографии

Создайте в корне репозитория папку `images` и загрузите в неё фотографии с такими именами:

```text
images/
├── profile.jpg
├── charger-board.jpg
├── charger-assembly.jpg
├── pcb-layout.jpg
└── pcb-hardware.jpg
```

Если фотография отсутствует, сайт автоматически покажет аккуратную заглушку с нужным именем файла. Подойдут форматы JPG, PNG и WebP; при смене расширения необходимо изменить путь в `index.html`.

Рекомендуемые размеры:

- портрет: от 1000 × 1250 px;
- фотографии проектов: от 1600 × 1000 px;
- размер одного файла желательно держать в пределах 1–2 МБ.

## 3. Добавьте новый проект

В `index.html` найдите блок `<article class="project-card reveal">`, скопируйте его внутри контейнера `project-grid`, затем измените фотографию, заголовок и описание.

## 4. Опубликуйте через GitHub Pages

1. Загрузите файлы в корень ветки `main` и сохраните изменения.
2. Откройте в репозитории **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Выберите ветку **main** и папку **/(root)**, затем нажмите **Save**.
5. После публикации ссылка появится в разделе Pages.

Для обычного репозитория адрес будет выглядеть так:

```text
https://USERNAME.github.io/REPOSITORY/
```

Если репозиторий называется `USERNAME.github.io`, адрес будет короче:

```text
https://USERNAME.github.io/
```

Официальная инструкция: <https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site>

## Локальный просмотр

Для быстрой проверки можно открыть `index.html` двойным щелчком. После изменения файлов обновите страницу в браузере.
